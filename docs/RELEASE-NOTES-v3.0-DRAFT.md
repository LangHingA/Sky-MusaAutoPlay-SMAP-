# SMAP v3.0.0「创造与分享」更新内容一览

## 创作与编辑
- 新增原生 `.smap` 多轨工程格式，支持保存、恢复及继续编辑。
- 多轨卷帘编辑，支持 Tap/Hold 音符、速度和拍号变化。
- 支持专业 SVG/PNG 图片谱导出，从图片恢复工程继续编辑。

## 导入与分享
- 导入统一为四个 TAB：SMAP 在线分享、离线、TXT/JSON、MIDI。
- 旧 TXT/JSON 曲谱自动转换后分享，无需手动改名或清理来源字段。
- 选择公开音轨，填写封面、曲名、原唱/作曲、制谱人、难度、标签及简介，自动读取演奏信息。
- Muse 在线发布与下载，支持固定版本分享码、历史版本及改编来源。
- 发布者、站长及有管理权限的账号，可在网页和软件内修改歌曲信息；不改动已发布的演奏内容。
- 改善云端曲库同步、下载及收藏信息展示，以及本地曲库自动刷新。

## 公告与更新
- 设置内新增公告入口，支持公告详情、未读标记和重要公告提示，由 Muse 后台管理。
- 可选择正式或测试更新通道。
- 后台差分下载，复用本地已有内容；小胶囊提示发现更新，下载完成后再询问重启。
- 更新清单签名与内容完整性校验，支持更新失败恢复。

## 界面与兼容
- 统一 G2 连续圆角，保留三主题和四语言。
- 改善多音轨选择、下拉层级与图标显示。
- 修复旧曲仅修改歌曲信息时的字段丢失问题，保留键数、Hold、时间单位和扩展字段。
- 精简程序安装目录，集中必要资源。
- 下载和导入的曲谱默认保存在程序旁的 `Song` 文件夹；本版暂不提供位置选择。
- 旧曲库迁移采用复制与校验，保留原件；程序更新不覆盖歌曲和个人设置。

## 升级说明
- 升级后请核对曲库、收藏和分享关联，确认正常后再清理旧目录及备份。
- v3.1 游戏内谱面映射尚未开放。
