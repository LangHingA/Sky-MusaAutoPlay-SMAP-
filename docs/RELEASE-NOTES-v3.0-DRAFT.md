# SMAP v3.0 更新说明 — 待用户审核

草稿，尚未发布。当前工程整顿候选为 **3.0.0-rc.3**，不得提前称为已发布 Stable。

## 功能更新

- 原生多轨 `.smap` 工程，支持 Tap/Hold、速度和拍号变化。
- 四 TAB 统一导入：在线分享、离线、TXT/JSON、MIDI。
- Muse 原生与历史曲谱在线分享，固定版本短码、历史版本、来源关系及有权限的歌曲信息编辑。
- 专业 SVG/PNG 图片谱导出与恢复编辑。
- 完善封面、作者、制谱人、难度、标签、简介和音轨选择；统一 G2 控件、三主题与四语言。
- 公告后台与客户端入口；更新通道选择、后台下载和就绪重启提示。

## 发行准备修复

- 旧曲仅改元信息时不重建音符，保留 4/8/15 键、Hold、时间单位、扩展字段及多曲数组其他项目；原子保存并保留备份。
- 修复跨通道更新验签身份选择，拒绝降级、错误签名与受损清单。
- 安装包增加签名发行证明与 SHA-256 校验；无可信证明时拒绝执行。
- 源码按职责分类；单文件程序入口使运行时依赖不再铺满安装根目录。
- 个人曲库与程序分离，旧数据复制、校验、备份与路径映射后使用，原件保留。
- 仅按精确哈希归档已知旧运行时；失败回退程序，不回退个人数据。

## 升级与限制

保留旧安装目录和迁移备份，核对歌曲、收藏和分享关联后再决定清理。便携模式须明确创建 `portable.mode`；普通配置不会自动导入新便携目录。

v3.1 游戏内谱面映射未开放。生产 Stable 签名身份、可选 Authenticode 签名、人工 UAC / 游戏 / 听觉验收，以及 README 和本说明审核仍需在正式发布前完成。
